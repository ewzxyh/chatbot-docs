# Documentação ChatCase

Site estático de documentação em pt-BR, com as coleções **Guia** e **Desenvolvedor**.

## Desenvolvimento

```bash
bun install
bun run dev
```

## Verificação

```bash
bun run lint
bun run types:check
bun run build
```

O projeto usa Next.js 16.3 Preview com Turbopack e Fumadocs.
