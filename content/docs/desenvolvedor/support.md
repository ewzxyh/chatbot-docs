Por favor, consulte este documento para entender como a equipe de ChatCase e a Comunidade de ChatCase oferece suporte para os planos gratuitos e a edição de código aberto do software ChatCase.

# # Problemas urgentes? Assinaturas pagas

Se você acha que seu problema é urgente, então você tem duas opções:

* Inscreva-se para um plano pago na [Edição em nuvem](https://chatcase.com/pricing-live-chat/)
* Obter um pacote de suporte para o [Enterprise Edition] (https://chatcase.com/chatcase-live-chat-on-premise/)

# # Eu preciso de ajuda mas não é tão urgente

Usar [nosso fórum] (https://chatcase.discourse.group/)

Espere pacientemente que um engenheiro considere ajudá-lo.

Se optar pela ajuda da comunidade em vez de apoio pago, por favor note que:

1. Ao abrir um problema, crie um pequeno, isolado, simples, reprodução do problema usando um editor de código online (como replit, codepen, codesandbox etc.) se possível e um repositório GitHub se não. O processo pode ajudá-lo a descobrir o problema subjacente (ou perceber que não é um problema com o projeto). Facilitará também que os mantenedores o ajudem a resolver o problema.
2. Sua pergunta deve ser bem documentada e você deve fornecer o código mínimo necessário para reproduzir o problema. Quando possível, sempre forneça um exemplo em execução para que dê evidência da questão.
3. Fazemos isso em nosso tempo livre. Por favor, respeita a nossa equipe.
4. Só porque é urgente para você significa que é urgente para todo o produto ChatCase ou comunidade
5. Por favor, responda as perguntas pacientemente e ajudá-los a tentar entender o seu problema
6. Ser rude com eles não vai ajudá-lo em nada
7. Por favor, note que postar a mesma questão em vários canais não vai ajudá-lo
8. Não abra um bug ainda. Quando você perguntar nos canais ou fóruns, devs ou outros ajudantes da comunidade lhe dirão se você realmente precisa abrir um problema. Frequentemente, se houver realmente um problema você não será o primeiro a experimentá-lo, então sempre verifique o fórum cuidadosamente para duplicatas. Use muitos termos de pesquisa diferentes e certifique-se de verificar também Problemas fechados (veja abaixo).
