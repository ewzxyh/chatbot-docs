Esta seção propõe um conjunto de tutoriais para mostrar algumas tarefas comuns que você pode abordar usando este recurso.

O objetivo principal dos webhooks é chamar uma ação definida pelo usuário (na forma de um endpoint HTTP) quando eventos específicos de ChatCase ocorrem.

O primeiro tutorial [Atribuição de Pedido Personalizado](https://developer.chatcase.com/apis/tutorials/webhooks/custom-assignment-pooled) aborda uma tarefa personalizada cada vez que um novo pedido é movido para um esquema de roteamento conjunto de um Departamento.

O segundo tutorial [Pedir transcrição ao fechar](https://developer.chatcase.com/apis/tutorials/webhooks/get-transcript-on-close) mostra como você pode obter sua transcrição de chat em cada operação de fechamento (ou seja, com o propósito de enviá-lo para seu CRM remoto para sincronizar conversas)

Mais tutoriais virão, fique ligado!
