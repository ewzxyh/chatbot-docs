[Acessar recurso externo](<https://www.youtube.com/watch?v=18zUVOadUdY>)
Descubra como instalar o ChatCase no seu site. Você pode instalá-lo simplesmente adicionando o código Javascript à sua página web. Siga as instruções abaixo, ou [veja este vídeo tutorial](https://youtu.be/18zUVOadUdY). Você pode adicionar um widget ChatCase ao seu site Prestashop adicionando o chat manualmente. &#x20;

Para fazer isso, abra o console, selecione o projeto a integrar, vá para **settings** > **instalação** e selecione integração **com código javascript**, agora pressione em **copy script** para copiar o código inteiro. Veja a imagem abaixo.

<figure><img src="/files/rJBgXs039WqKRMg2Fb1K" alt=""><figcaption></figcaption></figure>1. Antes de integrar o widget, você precisa desativar **HTML purificador** em sua área de administração PrestaShop. \
Para fazer isso, vá para **Parâmetros de compras** > **General** e desativar **Use a Biblioteca HTMLPurifier.** Veja a imagem abaixo.

<figure><img src="/files/cmgUKqJssd1NCB2oMZaF" alt=""><figcaption></figcaption></figure>1. Baixe o formulário **HTMLbox** de [aqui](https://mypresta.eu/modules/front-office-features/html-box.html).
2. No painel PrestaShop selecione **Module Manager** e depois **Upload um módulo**, para carregar o módulo **HTMLbox**. Veja a imagem abaixo.

<figure><img src="/files/iSS2GzCo5oH3aZmSzkgV" alt=""><figcaption></figcaption></figure>1. Uma vez que o módulo é carregado, vai para a configuração. Veja a imagem abaixo.

<figure><img src="/files/5BKkwI359sVUzpEf95mK" alt=""><figcaption></figcaption></figure>1. Selecione **Ferramentas** > **Código-fonte** e cole o código JavaScript do widget ChatCase. Veja a imagem abaixo.

<figure><img src="/files/q01CnbFGladj3QtfWgCm" alt=""><figcaption></figcaption></figure>1. Lembre-se de pressionar o botão **Salvar** no bottmo à direita da página para salvar suas alterações.
2. Vá ao seu site da Prestashop e verifique se você pode ver o widget ChatCase.

<figure><img src="/files/UKKaxqT1aGem1PIeeBKa" alt=""><figcaption></figcaption></figure>Agora ChatCase é oficialmente parte de seu site .
