Descubra como instalar o ChatCase no seu site. Você pode instalá-lo simplesmente adicionando o código Javascript à sua página web. Siga as instruções.

Você pode adicionar um widget ChatCase ao seu site Shopify adicionando o chat manualmente. \
Para fazer isso, abra o console, selecione o projeto a integrar, vá para **settings** > **instalação** e selecione integração **com código javascript**, agora pressione em **copy script** para copiar o código inteiro. Veja a imagem abaixo.

<figure><img src="/files/uSFzCxBh77iqr6YS2vd0" alt=""><figcaption></figcaption></figure>1. **Login** para o painel Shopify.
2. No Shopify, na seção **Temas**, você encontrará **o menu Ações**. Clique nele e selecione a opção **Editar código** na lista.

<figure><img src="/files/f4JUnd2TLP1xcwRYB2Lj" alt=""><figcaption></figcaption></figure>1. Selecione o arquivo **theme.liquid** na pasta **Layout** e cole o código JavaScript, pouco antes do fechamento **\</body>** Tag. Veja a imagem abaixo.

<figure><img src="/files/PQYb1l3xRaCG32ALpiZx" alt=""><figcaption></figcaption></figure>1. Lembre-se de pressionar o botão **Salvar** na parte superior direita da página para salvar suas alterações.
2. Vá para o seu site Shopify e verifique se você pode ver o widget ChatCase. &#x20;

<figure><img src="/files/u087rePXZA06939C7iVl" alt=""><figcaption></figcaption></figure>Bem agora ChatCase é integrado em seu site
