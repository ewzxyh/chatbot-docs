Descubra como instalar o ChatCase no seu site. Você pode instalá-lo simplesmente adicionando o código Javascript à sua página web. Siga as instruções.

Você pode adicionar um widget ChatCase ao seu site Wordpress adicionando o chat manualmente. \
Para fazer isso, abra o console, selecione o projeto a integrar, vá para **settings** > **instalação** e selecione integração **com código javascript**, agora pressione em **copy script** para copiar o código inteiro. Veja a imagem abaixo.

<figure><img src="/doc-images/EprJBGHVqN6hkoSJy0od.png" alt=""><figcaption></figcaption></figure>1. **Login** para o painel Wordpress.
2. No painel Wordpress selecione **Ferramentas** > **Theme File Editor**, selecione o tema ativo e, em seguida, selecione o arquivo **footer.html** e cole o código JavaScript no final da página. Veja a imagem abaixo.

<figure><img src="/doc-images/PiNKaxO7jqCPoYDcTY8O.png" alt=""><figcaption></figcaption></figure>1. Lembre-se de pressionar o botão **Atualizar Arquivo** na parte inferior esquerda da página para salvar suas alterações.
2. Vá ao seu site do Wordpress e verifique se você pode ver o widget ChatCase.
