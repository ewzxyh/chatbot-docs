Como instalar o ChatCase em Joomla

[Acessar recurso externo](<https://www.youtube.com/watch?v=A6NTGLzSZ4k>)
Descubra como instalar o ChatCase no seu site. Você pode instalá-lo simplesmente adicionando o código Javascript à sua página web. Siga estas instruções rápidas e fáceis.

Você pode adicionar um widget ChatCase ao seu site Joomla adicionando o chat manualmente. \
Para fazer isso, selecione o projeto a integrar, vá para S**ettings** > I**nstallation** e, após selecionar a seção **Joomla**, *pressa **o botão 'Copy script'** para copiar o código inteiro*. Veja as imagens abaixo.

<figure><img src="/doc-images/BHyY6QGJtoZaTTNlhxkW.png" alt=""><figcaption></figcaption></figure>

<figure><img src="/doc-images/ZQ6bRzqRkdbUMEneidxx.png" alt=""><figcaption></figcaption></figure>1. **Logue-se** no seu painel de administrador Joomla. Vá para **Sistema** > **Templates** > **Templates do Site** seção em seu Painel de Controle Joomla. Veja a imagem abaixo. &#x20;

<figure><img src="/doc-images/pkrKKZpo6XjX1ZBg4SBY.png" alt=""><figcaption></figcaption></figure>Carregue no seu modelo de tema padrão.

<figure><img src="/doc-images/FU8InX091MXTTMlUo4N6.png" alt=""><figcaption></figcaption></figure>1. Abra o arquivo **index.php** do menu do lado esquerdo, e cole o código JavaScript, pouco antes do fechamento **\</head>** Tag. Veja a imagem abaixo.

<figure><img src="/doc-images/rj7tEKGBgXl9tNdtbuDn.png" alt=""><figcaption></figcaption></figure>1. Lembre-se de pressionar o botão **Salvar** na parte superior esquerda da página para salvar suas alterações.
2. Vá para o seu site Joomla e verifique se você pode ver o widget ChatCase. &#x20;

<figure><img src="/doc-images/yXbPtUsuozk1MaDvOHDt.gif" alt=""><figcaption></figcaption></figure>Bem agora ChatCase é integrado em seu site
