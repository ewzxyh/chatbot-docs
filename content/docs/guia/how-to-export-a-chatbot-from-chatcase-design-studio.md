Exportar seu chatbot do ChatCase Design Studio não só permite fazer backup de seu trabalho ou migrar para outro projeto, mas também serve como uma ferramenta útil para solucionar problemas com a equipe de suporte. Siga os passos abaixo para exportar seu chatbot como um arquivo JSON.

Passo 1: Acesse o Design Studio<a href="#step-1-access-the-design-studio" id="step-1-access-the-design-studio"></a>* **Login** na sua conta ChatCase.
* ** Navigate** para o Design Studio onde seu chatbot está localizado.\
&#x20;

Passo 2: Abra a seção "Exportar Importação"<a href="#step-2-open-the-import-export-section" id="step-2-open-the-import-export-section"></a>

<figure><img src="/files/8QLxYAgZjnIJvc1jSk7t" alt=""><figcaption></figcaption></figure>* Na barra lateral esquerda do Design Studio, ** encontrar** o ícone "Configurações" representado por uma engrenagem.
* **Clique nele e vá para a guia "Exportar Importar".\
&#x20;

Passo 3: Exportar como JSONhttps://gethelp.chatcase.com/articles/how-to-export-a-chatbot-from-chatcase-design-studio/#step-3-export-as-json) <a href="#step-3-export-as-json" id="step-3-export-as-json"></a>* ** Procure por uma seção intitulada "JSON".
* **Clique no botão "Export As JSON". Isto iniciará o processo de exportação.\
&#x20;

Passo 4: Salve o arquivo JSONhttps://gethelp.chatcase.com/articles/how-to-export-a-chatbot-from-chatcase-design-studio/#step-4-save-the-json-file) <a href="#step-4-save-the-json-file" id="step-4-save-the-json-file"></a>* Um arquivo JSON contendo a configuração do seu chatbot será gerado.
* Quando solicitado, ** selecione** onde você deseja ** salvar** o arquivo em seu computador e confirmar para baixar.\
&#x20;

Passo 5: Verificar a Exportaçãohttps://gethelp.chatcase.com/articles/how-to-export-a-chatbot-from-chatcase-design-studio/#step-5-verify-the-export) <a href="#step-5-verify-the-export" id="step-5-verify-the-export"></a>* **Vá para o local do arquivo onde você salvou o arquivo JSON.
* **Abrir** com um editor de texto ou visualizador JSON para garantir que todos os dados do chatbot estejam presentes e exportados corretamente.\
&#x20;

Passo 6: Utilize o seu Chatbot Exportado para resolver problemashttps://gethelp.chatcase.com/articles/how-to-export-a-chatbot-from-chatcase-design-studio/#step-6-utilize-your-exported-chatbot-for-troubleshooting) <a href="#step-6-utilize-your-exported-chatbot-for-troubleshooting" id="step-6-utilize-your-exported-chatbot-for-troubleshooting"></a>* O arquivo JSON exportado pode ser um recurso inestimável para a equipe de suporte para ajudar a solucionar problemas.
* Compartilhar** este arquivo com nossa equipe de suporte para permitir que eles repliquem e diagnosticem quaisquer problemas com o chatbot.

** Nota importante sobre solução de problemas **

* Utilizando a função de exportação pode facilitar muito a equipe de suporte no diagnóstico e resolução de problemas rapidamente, garantindo o tempo de inatividade mínimo para seus serviços de chatbot.

Passo 7: Use o seu Chatbot Exportado & # x20;

* Com o arquivo JSON, você agora pode **importar** sua configuração do chatbot em outro projeto ou usá-lo como referência para desenvolvimentos futuros.\
&#x20;

**Reminder**

* Lide com o arquivo JSON com cuidado, pois contém a configuração completa do seu chatbot e pode incluir dados confidenciais.

** Parabéns! Você exportou com sucesso o seu chatbot do ChatCase Design Studio.
