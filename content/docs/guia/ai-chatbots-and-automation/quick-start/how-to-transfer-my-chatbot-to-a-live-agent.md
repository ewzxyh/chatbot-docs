Como transferir o meu chatbot para um agente ao vivo

Introdução<a href="#intro" id="intro"></a>E se, durante uma conversa, quiseres uma entrega de um "chatbot-humano"? A transferência de Chatbot-humano é quando você está transferindo a conversa de um chatbot para um agente ao vivo.

ChatCase No Code Visual Builder permite que você configure um chat ao vivo com a opção de entregar a conversa a um agente humano quando disponível. Além disso, se nenhum agente estiver online, você pode coletar informações de contato do cliente para acompanhamento. Neste tutorial, vamos guiá-lo através dos três passos fáceis para alcançar isso.

[Acessar recurso externo](<https://www.youtube.com/watch?embeds_referring_euri=https://gethelp.chatcase.com/&v=YuWQWdN6HjY>)
Passo 1: Configure a sua mensagem inicial<a href="#step-1-set-up-your-start-message" id="step-1-set-up-your-start-message"></a>* Comece configurando a mensagem inicial do seu chatbot.
* Adicione um botão à mensagem inicial para levar à entrega do agente quando clicado.

Passo 2: Desenhe um caminho para um novo bloco<a href="#step-2-draw-a-path-for-a-new-block" id="step-2-draw-a-path-for-a-new-block"></a>* Desenhe um caminho da porta de saída do botão para criar um novo bloco, escolhendo "Se Online Agent" no menu
* Nome (por exemplo, "Handoff").

Passo 3: Criar caminhos 2x<a href="#step-3-create-2x-paths" id="step-3-create-2x-paths"></a>* Da porta de saída “**Online**”, desenhe um caminho para criar um bloco correspondente escolhendo “**Agent Handoff**”. Você também pode incluir uma “Resposta” que aconselha o cliente que alguém está prestes a entrar no chat
* Caso o Agente não esteja online, desenhe um caminho do “**Else**” para criar um segundo bloco escolhendo um “**Reply**”, e inserindo, por exemplo, um convite para que seu cliente deixe uma mensagem

Parabéns! Você configurou com sucesso um chat ao vivo com a transferência do agente e a coleção de informações de contato usando o Construtor Visual Sem Código da ChatCase. Seu chatbot agora lidará com eficiência com interações do cliente, transferindo-as para agentes humanos quando disponíveis e coletando informações de contato para acompanhamento quando necessário.
