Use esta ação para popularizar a Base de Conhecimento usando um fluxo de automação.

Você pode selecionar o alvo Base de Conhecimento e usar esta ação para carregar um texto, documento ou URL específico durante um fluxo.

Muito útil para criar fluxos de auto-formação, onde algum conteúdo carregado por usuários ou agentes humanos são usados para povoar uma base de conhecimento
