Como gerir um chat inactivo

Introdução<a href="#intro" id="intro"></a>A opção "Sem Entrada" dentro do recurso Resposta Avançada aborda o problema de ter chats inativos. Este guia irá guiá-lo através dos passos para configurar o porto de saída Sem Entrada, que pode ser configurado para executar uma ação como fechar o chat ou enviar outra mensagem após um número especificado de segundos de inatividade.

Passo 1: Acesse as configurações de atraso<a href="#step-1-access-the-delay-settings" id="step-1-access-the-delay-settings"></a>1\. Localize o ícone de atraso no recurso Resposta avançada >> Sem entrada, que por padrão é definido como um atraso +10s.\
2\. Clique no ícone de atraso +10s para alterar o valor máximo para 120 segundos (2 minutos).

<figure><img src="/files/JPeNNx2b4Bn0APO7rw4x" alt=""><figcaption></figcaption></figure>Passo 2: Defina o valor máximo<a href="#step-2-set-the-maximum-value" id="step-2-set-the-maximum-value"></a>1\. Uma vez definido o indicador +2m (120 segundos), clique nele novamente para definir o número de segundos desejado para a ação Sem Entrada.\
2\. Você pode inserir valores como 7200 segundos (2 horas) ou até mesmo 100000 segundos, dependendo de sua exigência.

<figure><img src="/files/jpMy2xuvqCz7PDXnSRVX" alt=""><figcaption></figcaption></figure>Passo 3: Introduza os Segundos Desejados<a href="#step-3-input-the-desired-seconds" id="step-3-input-the-desired-seconds"></a>1\. Observe que a barra de segundos só permite entradas numéricas. Não aceitará quaisquer caracteres especiais ou letras.\
2\. Você pode aumentar ou diminuir o valor usando as setas fornecidas.\
3\. Alternativamente, você pode colar o número desejado diretamente no campo de entrada.

<figure><img src="/files/JEoJur9gGXiJPtto2L50" alt=""><figcaption></figcaption></figure>## # ** Configuração Exemplo #

\- Encerramento do Chat: Defina o porto de saída sem entrada para fechar o chat após 300 segundos (5 minutos) de inatividade.\
\- Enviando Outra Mensagem: Configure a porta de saída Sem Entrada para enviar uma mensagem de acompanhamento após 600 segundos (10 minutos) de inatividade.

Notas importantes

\- Certifique-se de que você só insira valores numéricos.\
\- A barra de segundos é projetada para evitar quaisquer caracteres não numéricos, garantindo uma configuração precisa.\
\- Você pode ajustar a duração entrando manualmente nos segundos ou usando as setas para ajustes menores.

Seguindo esses passos, você pode gerenciar efetivamente chats inativos usando a opção Sem Entrada do recurso Resposta Avançada, melhorando a responsividade e eficiência de suas interações de chat.
