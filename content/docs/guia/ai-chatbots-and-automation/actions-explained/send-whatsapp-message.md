Esta ação permite que você envie facilmente uma mensagem whatsapp usando um modelo do Whatsapp aprovado pela Meta.

Arraste a Ação Enviar o Whatsapp do menu lateral:

<figure><img src="/doc-images/icIPa6wFoDFdhbA4H4Ah.png" alt=""><figcaption></figcaption></figure>Agora você pode configurar a Ação usando o painel de detalhes como na figura a seguir.

No ID do número de telefone coloca o valor correspondente fornecido pelo Meta. É o ID associado ao seu número de meta-registrado do Whatsapp. Em seguida, escolha um modelo no menu “Escolha um modelo”. Na lista só aparecem os modelos Meta aprovados. Uma vez que você escolher um modelo simplesmente preencha os valores do modelo. Você pode usar valores estáticos ou atributos de fluxo.

<figure><img src="/doc-images/LOCo3uu27LI5sCRzU38k.png" alt=""><figcaption></figcaption></figure>Você também pode ver uma pré-visualização do modelo usando o botão de pré-visualização no modelo:

<figure><img src="/doc-images/mc95ed036cnRH3ARAF1a.png" alt=""><figcaption></figcaption></figure>Agora, uma vez que a automação é invocada O número de destino (número de telefone) receberá a mensagem preenchida.
