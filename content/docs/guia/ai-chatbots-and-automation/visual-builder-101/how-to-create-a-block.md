Como criar um bloco

Um dos aspectos essenciais para projetar o fluxo de trabalho do seu Agente de IA é entender como usar **Blocks**.\
Os blocos são os elementos centrais da conversa do seu Agente de IA, e você pode conectá-los para criar interações envolventes.\
Neste tutorial, vamos guiá-lo através do processo de criação de um fluxo básico de trabalho de IA usando Blocos em ChatCase.

<figure><img src="/doc-images/ViysiTJ1tmZHrRJAljBM.gif" alt=""><figcaption></figcaption></figure>Em ChatCase, conversas com o AI Agent são construídas usando blocos. Os blocos são os elementos fundamentais de um fluxo de trabalho de IA.

No lado esquerdo da interface ChatCase, você encontrará uma barra de ferramentas. Clique no ícone "AI".\
Irá aparecer um menu suspenso.

Neste menu, selecione uma ação como [ChatGPT Task](/docs/guia/ai-chatbots-and-automation/actions-explained/chatgpt-task) \
As ações são os principais componentes de seus blocos.

<figure><img src="/doc-images/yQkpClhmvkLqggR7cBsz.gif" alt=""><figcaption></figcaption></figure>Arraste a ação "ChatGPT task" da barra de ferramentas para o construtor visual, também conhecido como Design Studio, e solte-a onde quiser na tela.

Parabéns! Você agora criou um novo Bloco.

Para criar outro bloco, comece desenhando um caminho do porto de saída.\
Esta ação irá abrir o mesmo menu suspenso que usou anteriormente para seleccionar uma "ação".

Escolha uma "Ação" do menu que formará seu segundo bloco. Esta ação pode ser um "[Reply](/docs/guia/ai-chatbots-and-automation/actions-explained/reply-action)," "Condition," ou qualquer outra opção que se encaixe no fluxo de trabalho do seu Agente de IA.

Depois de selecionar a ação, outro bloco será criado automaticamente na tela.

<figure><img src="/doc-images/KMUHzvHqtcDDyYzJfP2m.gif" alt=""><figcaption></figcaption></figure>Uma vez satisfeito com o fluxo de trabalho do seu Agente de IA, você pode lançá-lo e disponibilizá-lo aos usuários em seu site ou em qualquer outra plataforma.

Confira nossos guias de instalação aqui: [Web Integrations](/docs/guia/web-integrations)

Parabéns! Você criou com sucesso um fluxo básico de conversação para o seu Agente de IA usando Blocos em ChatCase. Você pode continuar a construir sobre esta base para criar interações mais complexas e envolventes.
