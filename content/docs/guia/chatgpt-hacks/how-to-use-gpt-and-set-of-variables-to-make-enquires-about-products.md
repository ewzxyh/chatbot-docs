# ### **1. Primeiro, selecione “Globals” no menu da barra lateral esquerda.**&#x20;

Em seguida, adicione uma nova variável global, como mostrado na imagem abaixo.

<figure><img src="/doc-images/Yvgqw10l5rsh1kxEjjAG.png" alt=""><figcaption></figcaption></figure>#### **2. Em seguida, escolha uma chave para suas variáveis e insira sua lista de preços na seção Valor**

ver imagem abaixo

<figure><img src="/doc-images/pzkPtS7LXe02k5yDQbAa.png" alt=""><figcaption></figcaption></figure>#### **3. Agora, volte para a seção Blocks para projetar o bot**

Você precisará de uma ação chamada “Resposta do Usuário Capture” para capturar a resposta do cliente. Você pode atribuir um atributo a ele. Neste caso, eu usei ‘UserReply’ como o atributo

<figure><img src="/doc-images/R5CNneYjNVg5YJE5Omig.png" alt=""><figcaption></figcaption></figure>#### **4. Para o próximo bloco, use a ação ‘ChatGPT Task’**

Você pode ver o prompt que inclui o atributo da Global criado mais cedo em 'preços'. Obter o prompt perfeito pode exigir algumas tentativas para obtê-lo corretamente.

<figure><img src="/doc-images/o6R8TtsLxLux8aTKcA4T.png" alt=""><figcaption></figcaption></figure>**5. Finalmente, adicione um novo bloco de resposta e simplesmente escolha o gpt\ reply.**

<figure><img src="/doc-images/zH160WvZ9nWZ3EA5Aon4.png" alt=""><figcaption></figcaption></figure>É isso aí! No vídeo abaixo, você pode ver como o bot encontra o preço na tabela e compartilha com o usuário.
