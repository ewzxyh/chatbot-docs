Como mudar uma língua

O usuário pode alterar o idioma padrão clicando na imagem do perfil no canto superior direito e selecionando Editar perfil.

<figure><img src="/doc-images/6vFs4umyX3qBIFCLAKB7.png" alt=""><figcaption></figcaption></figure>A opção Editar perfil dá-lhe uma lista de preferências de perfil pessoal. Role para baixo e você vai encontrar as configurações do idioma Dashboard, com a opção padrão em "Automatic", que é geralmente Inglês, baseado não só nas configurações do navegador, mas também se um idioma específico não é encontrado entre o disponível.

<figure><img src="/doc-images/vlyvIBxvhhQO6kjTZAzx.png" alt=""><figcaption></figcaption></figure>Se você quiser um idioma específico entre os suportados, selecione-o na segunda opção “Escolha seu idioma preferido”.

<figure><img src="/doc-images/s01eI3SySd7MSlavJKY8.png" alt=""><figcaption></figcaption></figure>Depois de selecionar seu novo idioma, lembre-se de recarregar o aplicativo para que a alteração faça efeito.

Web widget

Widget também seleciona automaticamente um idioma com base nas configurações do navegador. Widget vem com as mesmas linguagens pré-traduzidas da aplicação console.

Idiomas pré- traduzidos Widget são os mesmos da seção de idiomas suportados

\
** Mudar as línguas do Widget **

O widget Web fornece uma ferramenta para permitir personalizar as etiquetas do Widget com base em suas preferências.

O widget Web implementa o idioma do navegador do usuário final por padrão, se disponível. Caso contrário, é padrão para Inglês.

Para modificar o idioma Web widget “pivot” vá para Configurações > Opção de widget do painel. Agora abra a seção Idiomas e clique no link “Adicionar idiomas”, como na seguinte imagem:

<figure><img src="/doc-images/F6EazPXk3ujt6jGhEtUG.png" alt=""><figcaption></figcaption></figure>A janela Multilanguage será aberta (com o Inglês como idioma padrão):

<figure><img src="/doc-images/HiLS8tRCRI1sBR0Wqwaf.png" alt=""><figcaption></figcaption></figure>** Adicionar um novo idioma**

Para adicionar um novo idioma, fique na janela Multilanguage que acabamos de abrir.

Você pode adicionar quantas línguas quiser entre as suportadas. Basta clicar no botão "Adicionar" no cabeçalho superior. Um menu suspenso será aberto, onde você pode escolher seu idioma preferido.

<figure><img src="/doc-images/GVQ63Vzj7brvpWaJOlzg.png" alt=""><figcaption></figcaption></figure>Há dois grupos de línguas. ** Pré-traduzido** e ** A ser-traduzido**. Se você escolher um idioma ainda não traduzido nós forneceremos etiquetas pré-cheias com a tradução em inglês para ajudá-lo a simplificar o significado do rótulo e o esforço de tradução.

<figure><img src="/doc-images/ZTCStQELzX7ZQxIe3QUx.png" alt=""><figcaption></figcaption></figure>O idioma adicionado aparece na barra superior. Você pode modificar todas as etiquetas que quiser. Você também pode fazer qualquer idioma o padrão pressionando o botão "**MAKE DEFAULT**". Uma vez que você faz um idioma "padrão", ele será automaticamente selecionado cada vez que um idioma widget não é encontrado nos idiomas suportados (aqueles adicionados à visão Multilinguagem). Lembre-se que o “linguagem giratória” é o idioma definido no navegador do usuário final, onde o widget é carregado e usado.

Na próxima janela Multilanguage você será capaz de alterar todos os rótulos no widget para o idioma selecionado. O padrão é Inglês, mas você pode adicionar novos idiomas.
