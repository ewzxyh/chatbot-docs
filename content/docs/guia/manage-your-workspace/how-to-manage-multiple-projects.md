O que queremos dizer com um projeto<a href="#what-do-we-mean-by-a-project" id="what-do-we-mean-by-a-project"></a>Se você é uma agência ou trabalha para diferentes marcas, você pode configurar projetos para cada uma e, em seguida, alternar entre eles para ter tudo estruturado. ChatCase permite que você crie vários projetos sob o mesmo login de e-mail, o que torna mais fácil gerenciar chats para vários sites ou aplicativos.

Não aconselhamos o gerenciamento de publicações de diferentes marcas no mesmo projeto, pois estatísticas, canais e usuários não serão separados. Cada projeto também pode ser marcado apenas com uma identidade.

Cada vez que você fizer login no seu projeto, você verá estatísticas sobre cada projeto e receberá links diretos para conversas, campanhas e muito mais. Todas as notificações push para todos os projetos também são exibidas.

Um projeto é basicamente uma conta separada do ChatCase (com sua própria configuração independente), mas você pode usar o mesmo login de email para cada projeto e alternar entre os projetos rapidamente.

Como adicionar novos projetos<a href="#how-to-add-new-projects" id="how-to-add-new-projects"></a>Adicionar um novo projeto é muito simples; basta clicar na seta ao lado do seu nome atual do projeto no canto superior direito e pressionar o botão "Adicionar um projeto". Isso permitirá que você crie um novo projeto.

<figure><img src="/doc-images/K43l2DJbw5qd9nmumpHY.png" alt=""><figcaption></figcaption></figure>Como configurar novos projetos<a href="#how-to-configure-new-projects" id="how-to-configure-new-projects"></a>Clicar no botão "Adicionar um projeto" lhe apresentará uma turnê para configurar um projeto. Você será solicitado para o seu nome do projeto (por exemplo, seu nome do site). Depois disso clique no botão "Criar projeto".

Como alternar entre projetos

Para mudar o projeto – na seta ao lado do seu nome atual do projeto na parte superior direita e clique no botão "Ver todos os projetos". Clique no nome do projeto que você gostaria de entrar.
